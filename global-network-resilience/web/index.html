Como o projeto se interliga

Scripts Python — coleta de dados

Executam varredura TCP (múltiplas portas), ICMP ping e traceroute MTR em paralelo contra os endpoints de aterrissagem de cada cabo. Uso real: ao rodar a Sonda Diária, o script itera todos os cabos ativos, testa conectividade, mede latência/jitter/perda de pacotes e salva os resultados em arquivos JSON de checkpoint — que depois são importados para o banco via UPSERT.

run_daily_telemetry_tasks.shcheckpoint_*.jsonprobe_full_*.json
grava JSON · importa para BD
PostgreSQL (Railway) — persistência

Armazena a topologia de cabos, pontos de aterrissagem, amostras de telemetria e hops de rota em 12 tabelas relacionadas. Uso real: cable_telemetry_samples recebe cada medição com UPSERT; views rollup_1h e rollup_5m calculam médias, p95 e pico sem tabelas físicas redundantes — qualquer query ao Explorador DB lê diretamente dessas views.

cableslanding_pointscable_telemetry_samplescable_telemetry_hopstelemetry_alerts
consulta SQL · serve JSON
API PHP (api.php) — camada de serviço

Único ponto de entrada entre o frontend e o banco. Uso real: cada aba do site dispara um fetch() diferente — o Mapa chama ?action=all para listar cabos com coordenadas; a Sonda chama ?action=probe para testar um endpoint ao vivo; o Explorador DB chama ?action=db_browse com paginação. Rate limiting por SHA-256 do IP previne abuso.

?action=all?action=probe?action=db_browse?action=summary?action=daily_start
fetch() · renderiza no cliente
Frontend Vanilla JS — visualização

SPA sem bundler ou framework. Uso real: ao abrir o Mapa, globe.gl desenha cada cabo como um arco 3D animado sobre o globo — a cor indica status (verde = operacional, amarelo = alerta, cinza = inativo). O Explorador DB mostra tabelas paginadas com filtros. A Sonda ao Vivo testa um endpoint e exibe latência, jitter e hops de rota em tempo real. O app é instalável como PWA via service worker.
