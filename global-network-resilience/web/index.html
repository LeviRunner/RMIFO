Endpoints e geografia
FUNCAO_ROTA_TOP3
Selecione os países e execute a análise de rotas.
FUNCAO_CORTE_ISOLAMENTO
Selecione o par de países para analisar cabos críticos.
FUNCAO_ENDPOINT_RISCO
Selecione um país para mapear endpoints de risco.
FUNCAO_TELEMETRIA_CABO
Telemetria avançada: execute para ver indicadores do cabo e base para análises futuras.
SONDA_DE_REDE
Selecione um cabo e endpoint para executar a sonda de conectividade de rede. A sonda testa TCP connect, estima RTT e perda de pacotes, e simula a rota de hops até o endpoint.
